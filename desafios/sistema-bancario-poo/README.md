# Sistema Bancário em Python - POO

## Descrição
Projeto desenvolvido como desafio da DIO com o objetivo de refatorar um sistema bancário que utilizava dicionários, passando a armazenar os dados de clientes e contas bancárias em objetos, seguindo os conceitos de Programação Orientada a Objetos.

## Funcionalidades
- Criar usuário
- Criar conta corrente
- Depositar
- Sacar
- Exibir extrato
- Listar contas

## Conceitos aplicados
- Classes e objetos
- Herança
- Encapsulamento
- Abstração
- Classe abstrata
- Composição

## Estrutura de classes
- Cliente
- PessoaFisica
- Conta
- ContaCorrente
- Historico
- Transacao
- Deposito
- Saque

1. Clone o repositório
2. Acesse a pasta do projeto
